# Authentication — svecicezaauto.rs

> This is a public e-commerce catalog website. No authentication is required to access any content.

## Access Policy

- **Authentication Required**: No
- **API Keys**: Not required
- **OAuth**: Not implemented
- **Rate Limiting**: Standard web server limits apply

## Available Endpoints

- **Product Catalog**: All product pages are publicly accessible at `/proizvod/{id}`
- **Category Pages**: Browse by category at `/kategorija/{slug}`
- **Search Index**: JSON search index available at `/search-index.json`
- **Sitemap**: Full XML sitemap at `/sitemap-index.xml`
- **AI Summary**: Machine-readable summary at `/llms.txt`
