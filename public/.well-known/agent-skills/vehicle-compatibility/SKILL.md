# Check Vehicle Compatibility

View which vehicles a specific ignition part fits.

## Usage

1. Navigate to a product page: `https://svecicezaauto.rs/proizvod/{id}`
2. Each product page contains a vehicle compatibility table with:
   - **Make**: Vehicle manufacturer (e.g., BMW, Audi, VW)
   - **Models**: Specific model names (e.g., Golf IV, Passat B5)
   - **Engine**: Engine type/displacement range
   - **Year**: Production year range (from–to)
